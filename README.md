# OOP Concepts Revision – Java Practical

## 📌 About the Project

This project was created as a practical session during an OOP (Object-Oriented Programming) Concepts Revision Session conducted for our batch.

The main purpose of this practical was to understand and apply the four main OOP concepts in Java by developing a simple GUI application.

The application uses Java Swing to create a graphical user interface and writes data into a file.

## 🎯 OOP Concepts Covered

This project demonstrates the following Object-Oriented Programming concepts:

### 1. Inheritance

Inheritance allows a class to acquire properties and methods from another class.

### 2. Polymorphism

Polymorphism allows methods to behave in different ways. This practical includes:

* **Method Overriding** – Redefining a method in a child class.
* **Method Overloading** – Creating multiple methods with the same name but different parameters.

### 3. Encapsulation

Encapsulation protects data by using private variables and providing controlled access through methods.

### 4. Abstraction

Abstraction hides implementation details and shows only the essential features of an object.

## 🛠️ Technologies Used

## ✨ Features

* Simple graphical user interface (GUI)
